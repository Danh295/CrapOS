Glossary

Every lesson uses these terms exactly as defined here.

TermMeaning
Real modeThe CPU's original mode: 20-bit segmented addresses (1 MB), no memory protection. The BIOS and your boot sector run in it.
Segment, offsetThe two 16-bit halves of a real-mode address. Physical address = segment × 16 + offset.
BIOSFirmware that finds the boot disk, loads sector 0, and offers services to call via int.
Boot sectorThe first 512-byte sector of the disk. Loaded at 0x7C00 and only bootable if it ends in 55 AA.
BIOS interrupt callA software interrupt (int N) that runs a BIOS service. The function number goes in AH.
int 0x10Video services. With AH=0Eh, prints the character in AL (teletype output).
int 0x13Disk services (read, write, format sectors). Used later to load the second stage.
int 0x16Keyboard services. With AH=00h, waits for a key and returns its ASCII value in AL and scan code in AH.
putsCrapOS's own subroutine (not BIOS). Prints the null-terminated string at ds:si by calling int 0x10 once per character.
lodsbLoad the byte at DS:SI into AL, then increment SI.
First stage / second stageThe first stage is the 512-byte boot sector. A second stage is more code it loads from disk, so the OS can be larger than one sector.
Stage 2The code the boot sector loads from disk (4 sectors at 0x7E00). We say "stage 2", not "kernel": there is no protected mode and no C. CrapOS's shell lives here.
Boot driveThe drive number the BIOS leaves in DL when it jumps to the boot sector. The loader must keep it to read from the same disk.
Load addressThe memory address stage 2 is read to: 0x7E00, the first byte after the boot sector.
Sector (CHS)How int 0x13 AH=02h addresses the disk: cylinder, head, sector. Sector numbers start at 1, so stage 2 starts at sector 2.
CommandOne named action the stage 2 shell runs: help, reboot, crap or clear.
Shell loopStage 2's main loop: show a prompt, read a line into the 64-byte buffer, look the command up and run it.
